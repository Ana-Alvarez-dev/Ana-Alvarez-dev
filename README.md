## 👩‍💻 About Me

I'm a **Systems Engineering and Software Development student** focused on **Java Backend Development and Backend Engineering**.

I'm currently building towards my first professional opportunity as a **Java Backend Developer**, while developing strong foundations in software engineering, testing, databases, architecture and backend systems.

My learning approach is based on understanding before implementing and building software that I can **explain, test, document and defend technically**.

I focus on the complete engineering process:

```text
Problem
   ↓
Requirements
   ↓
Modelling
   ↓
Architecture
   ↓
Implementation
   ↓
Testing
   ↓
Operation
   ↓
```

My goal is not to accumulate technologies, but to build **verifiable evidence of engineering capability**.

## 🧠 Engineering Principles

- Understand before implementing.
- Model before adding complexity.
- Test behaviour, not implementation details.
- Use architecture to solve problems, not to decorate projects.
- Document important technical decisions.
- Prefer simple systems that can evolve.
- Measure before optimising.
- Do not use microservices only because they are popular.
