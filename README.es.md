## 👩‍💻 Sobre mí

Soy estudiante de **Ingeniería en Sistemas y Desarrollo de Software**, con foco en **desarrollo Backend con Java y Backend Engineering**.

Actualmente estoy construyendo mi perfil para acceder a mi primera oportunidad profesional como **Desarrolladora Backend Java**, mientras fortalezco fundamentos en ingeniería de software, testing, bases de datos, arquitectura y sistemas backend.

Mi enfoque de aprendizaje se basa en **comprender antes de implementar** y construir software que pueda **explicar, probar, documentar y defender técnicamente**.

Me interesa comprender el proceso completo de ingeniería:

```text
Problema
   ↓
Requisitos
   ↓
Modelado
   ↓
Arquitectura
   ↓
Implementación
   ↓
Testing
   ↓
Operación
   ↓
Decisiones técnicas
   ↓
Retrospectiva
```

Mi objetivo no es acumular tecnologías, sino construir **evidencia verificable de capacidad técnica**.

## 🧠 Principios de ingeniería

- Comprender antes de implementar.
- Modelar antes de agregar complejidad.
- Probar comportamiento, no detalles internos de implementación.
- Utilizar arquitectura para resolver problemas, no para decorar proyectos.
- Documentar las decisiones técnicas importantes.
- Preferir sistemas simples que puedan evolucionar.
- Medir antes de optimizar.
- No utilizar microservicios únicamente porque sean populares.

## 🎯 Objetivo profesional

Estoy construyendo mi perfil para acceder a mi **primera oportunidad profesional como Desarrolladora Backend Java**, con una evolución a largo plazo hacia **Backend Engineering**.

Quiero que mis repositorios demuestren mediante evidencia que puedo:

- comprender un problema y su contexto;
- identificar requisitos y reglas de negocio;
- modelar una solución;
- justificar decisiones técnicas;
- implementar software mantenible;
- probar comportamiento crítico;
- documentar trade-offs;
- utilizar Git y flujos de trabajo colaborativos;
- operar y evolucionar un sistema.

Quiero que cada proyecto muestre no solamente **qué construí**, sino también **cómo razoné, qué decisiones tomé y qué evidencia respalda la solución**.
